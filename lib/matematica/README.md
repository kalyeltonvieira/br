# Matemática

Módulo `matematica` da biblioteca padrão BR.

## Escopo

Este módulo cobre operações básicas, avançadas, estatística e números aleatórios.

## Arquivos

- `matematica.br`: implementação principal.
- `api.br`: API complementar e metadados.
- `matematica.bri`: contrato público.
- `matematica.brd`: documentação gerada/estática.
- `exemplos/basico.br`: exemplo executável.
- `testes/matematica_teste.brt`: testes do módulo.

## API Inicial

- `somar(a, b)`: Soma dois valores.
- `subtrair(a, b)`: Subtrai dois valores.
- `multiplicar(a, b)`: Multiplica dois valores.
- `dividir(a, b)`: Divide dois valores.
