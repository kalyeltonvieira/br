# Testes

Módulo `testes` da biblioteca padrão BR.

## Escopo

Este módulo cobre testes unitários, assertivas, mocks e cobertura.

## Arquivos

- `testes.br`: implementação principal.
- `api.br`: API complementar e metadados.
- `testes.bri`: contrato público.
- `testes.brd`: documentação gerada/estática.
- `exemplos/basico.br`: exemplo executável.
- `testes/testes_teste.brt`: testes do módulo.

## API Inicial

- `igual(a, b)`: Assertiva de igualdade.
- `eh_verdadeiro(valor)`: Assertiva verdadeira.
- `eh_falso(valor)`: Assertiva falsa.
- `mock(nome_item)`: Cria mock nomeado.
