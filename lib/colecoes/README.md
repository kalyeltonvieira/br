# Coleções

Módulo `colecoes` da biblioteca padrão BR.

## Escopo

Este módulo cobre listas, dicionários, conjuntos, filas, pilhas e funções funcionais.

## Arquivos

- `colecoes.br`: implementação principal.
- `api.br`: API complementar e metadados.
- `colecoes.bri`: contrato público.
- `colecoes.brd`: documentação gerada/estática.
- `exemplos/basico.br`: exemplo executável.
- `testes/colecoes_teste.brt`: testes do módulo.

## API Inicial

- `tamanho(dados)`: Retorna tamanho de coleção.
- `vazia(dados)`: Verifica se coleção está vazia.
- `primeiro(dados)`: Retorna primeiro item.
- `ordenar(dados)`: Ordena uma coleção.
